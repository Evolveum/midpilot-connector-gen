= Midpilot Connector Generator — Documentation
:toc: left
:toclevels: 2

Midpilot Connector Generator is a FastAPI backend that uses LLMs to generate
https://evolveum.com/midpoint/[midPoint] connectors for third-party systems.
Given an application name and its documentation or database schema, it builds
a structured integration model (object classes, attributes, endpoints where
applicable, and authentication) and generates the Groovy connector code. REST
and SCIM documentation can be discovered and scraped; SQL schemas are uploaded
directly.

== API reference

* link:api/openapi.json[OpenAPI specification] — generated file, do not edit
  by hand; regenerate with `uv run poe export-openapi` after changing routes
  or schemas.
* When the service is running: http://localhost:8090/docs[Swagger UI] and
  http://localhost:8090/redoc[ReDoc]

== Extending this documentation

* One page per topic; keep pages short and link between them with
  `+link:page.adoc[Text]+` (renders correctly on GitHub, unlike `xref:`).
* Pipeline stages live under `pipeline/`; new cross-cutting topics get a new
  top-level page and a row in the table above.
* `api/` holds generated artifacts (OpenAPI spec), `images/` holds diagrams and
  `examples/` holds sample payloads referenced from a page; hand-written pages
  stay in the top level and `pipeline/`.
* Use `NOTE:` / `IMPORTANT:` / `WARNING:` admonitions for pitfalls, so they
  stand out when skimming.
* Prefer linking to source files (e.g. `src/config/digester.py`) over copying
  exhaustive lists into the docs — the code is the source of truth for
  defaults and complete option lists.
