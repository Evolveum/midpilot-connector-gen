= SQL delete operation

The database connector deletes the row identified by the primary key of the mapped table. The
`delete` block only declares that the built-in delete is used for this object class.

== Built-in delete

[source,groovy]
----
objectClass("m_user") {
    delete {
        sql {
            builtIn {
                enabled true
            }
        }
    }
}
----

`enabled` is the only key `builtIn` needs for delete. Do not write statements, predicates or
cascade handling into the operation block.

== Rules

* Never render a table name as `endpoint(...)`, a path, or a hand-written `DELETE` statement.
* Never generate REST or SCIM constructs.
* A conndev SQL export carries no primary keys or foreign keys. When no attribute is marked
  `primaryKey`, leave a TODO instead of guessing the identity column from a column name.
* Never invent cascade deletes. When the documentation shows a foreign key whose cascade behavior
  is not documented, leave a TODO naming the dependency.
* When the schema or the documentation shows a soft-delete column, do not silently turn the delete
  into an update; leave a TODO stating that deactivation may be required instead.
